# Forensic Port Scanner

A professional port scanner tool designed for cybersecurity forensic teams.

## Features

- TCP/UDP/SYN scanning
- Service detection and version identification
- OS fingerprinting
- Secure data storage with encryption
- Audit logging for forensic purposes
- Export results in multiple formats (JSON, CSV, PDF)
- RESTful API for integration with other tools
